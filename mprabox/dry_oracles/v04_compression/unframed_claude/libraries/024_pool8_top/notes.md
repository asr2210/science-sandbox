# Experiment 024 — 8-motif pool (seed=53)

## Result
eval_01 = 0.3469. Roughly same as 32-pool population mean (0.344).

## Interpretation
8 motifs is too few — each motif appears ~6250 times, library becomes
nearly-homogeneous in motif content. Bimodality effect creeps in (like
exp 010). Lower bound of useful pool size around 16.
